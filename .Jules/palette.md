## 2024-05-24 - Accessible Tab Pattern with Tailwind
**Learning:** When building custom interactive components (like tabs) in React, explicitly implementing standard WAI-ARIA roles (`tablist`, `tab`, `tabpanel`) alongside appropriate state indicators (`aria-selected`) and connection IDs (`aria-controls`, `aria-labelledby`) is crucial. Native elements like `<button>` handle keyboard focus intrinsically, but visual feedback must still be defined using Tailwind`s `focus-visible:` pseudo-class (e.g., `focus-visible:ring-2`) to provide a clear focus ring for keyboard users without disrupting mouse interactions.
**Action:** Always implement full ARIA mappings for custom component abstractions that mimic native roles. Ensure `focus-visible` styling is present on focusable non-button containers like tab panels.
