## 2024-04-26 - React Synthetic Focus Bubbling for Accessible Wrappers
**Learning:** In React, `onFocus` and `onBlur` events use a synthetic event system that allows them to bubble up the component tree, unlike native DOM `focus` and `blur` events which do not bubble (unless using event delegation with capture phase). This means when building accessible UI wrappers like `Tooltip`, you can place `onFocus` and `onBlur` handlers directly on a non-focusable parent `div`. When an interactive child element (like an `<input>` or `<button>`) receives focus, the event bubbles to the parent wrapper naturally.
**Action:** When creating wrapper components (Tooltips, Dropdown containers, etc.) that need to react to keyboard focus of their children, utilize React's bubbling `onFocus`/`onBlur` on the parent container instead of drilling focus handlers down into every child component or relying solely on mouse events.
